# Dom Bolo — Modelo C (React)

Projeto Vite + React. Estrutura: `index.html` (HTML), `src/styles.css` (CSS), `src/**/*.jsx` (React) e `src/hooks/*.js` (JavaScript: barra de progresso e rolagem suave).

```bash
npm install
npm run dev      # desenvolvimento
npm run build    # gera a pasta dist/ para publicar
```

Textos, telefone, endereço, horários e sabores ficam em `src/data.js`.
